## Headline

Coding Agent Failure Atlas

## Subhead

A structured look at how coding agents behave on small software tasks — what they
get right, where they go wrong, and why.

## Intro paragraph

This project gathers field notes from running coding agents against small,
self-contained tasks. Each run is recorded with the same evidence — the prompt,
a transcript summary, the code diff, test output, and a human judgment — so the
behavior can be reviewed rather than guessed at.

## What you'll find

- A consistent template for capturing each run.
- A taxonomy of the failure patterns observed.
- A coarse 1–5 rubric used during review.
- Cross-run insights, kept qualitative on purpose.

## Honest framing

This is not a benchmark and not a production evaluation system. The task set is
small and curated, and scoring relies on human judgment. Read it as careful
observation, not measurement.

## Call to action

Browse the runs, read the methodology, and form your own view.
